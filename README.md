## 📌 Featured Projects

### 🦊 **OpenProtogen**

Open-source firmware for a Protogen smart visor. A highly modular system where every component does exactly one job.

- **glatt** - My custom SDF (Signed Distance Fields) graphics engine. Written in pure C, using floating-point math to render smooth, anti-aliased shapes and procedural animations instead of bitmaps.
- **[maxframe](https://github.com/slpuk/maxframe)** - An optimized driver for MAX72XX LED matrices. Features my custom "JumpBack" algorithm for seamless cascading and snake-routing.
- **audaviz** - Real-time audio visualization using INMP441.

`C` `ESP32-S3` `SDF` `Math` `Hardware`

### 📶 [**lwproto**](https://github.com/lwproto)

A family of independent, lightweight protocols designed for resource-constrained devices and low-bandwidth networks.

- **[Fink](https://github.com/lwproto/fink)** - Ultra-light discrete protocol with only 4 bytes of overhead. Perfect for telemetry and short commands.

***"Don't turn a matchstick into a multicooker!"***

`Protocols` `IoT` `Embedded` `C`

### 🛠️ **irubian**

A custom Linux distribution (based on Armbian) for the iRULU exPro X1 tablet. Built from scratch, including reverse-engineering stock drivers, configuring U-Boot, and patching the Device Tree.

`Linux` `U-Boot` `Armbian` `Device Tree` `C`

### 🕹️ [**Ultimate Redstone+**](https://modrinth.com/resourcepack/ultimate-redstone-plus)

A popular Minecraft resource pack that adds visual indicators for Redstone components.
**8,600+ downloads** and counting.

`Minecraft` `Game Dev` `UI/UX` `Pixel Art`
